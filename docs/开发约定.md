## 一、词库体系（换词库 / 加词库必读）

### 双库双层
- `all` ＝ 云端考研词库 4801 词。
- `ielts` ＝ 雅思 4491 词，**两层数据**：
  1. 云端富词条 `worddict_ielts`；
  2. 内置基础词条 `data/libraries/ielts.js`（423KB，主包内，离线兜底）。

### 统一入口（新增词库只改这两处）
1. **`services/libraries.js`**
   - `LIBRARIES` + `getLibraryWords` / `getLibraryEntries` / `getLibraryEntry`
   - 小写索引，查找 O(1)。
2. **`services/wordEnrich.js`**
   - L1 本地（同步）→ L2 云端富词条；
   - `enrichSync` / `enrichCloud` / `enrichOne` / `enrichBatch`；
   - **双 Map 缓存**（one / cloud 分开，防 L1 简明结果挡住 L2 富结果）；
   - 详情页标准姿势：`enrichSync` 即时上屏 → `enrichCloud` 到达后无缝升级。
   - `fromCloudEntry` 已 export（音标字段两集合不同名：雅思 `phonetic_uk`，考研无音标字段）。

### 浏览页：禁半云端半本地混排
`ensureLocalCloudDecision` 一次性决定数据源；云端单次失败只回落**本轮**
（`cloudBatch` 必须同步置回 false）。

### 集合身份校验（2026-10-20 修）
- `worddict` 云函数所有 return 加 `col: COL`；
- `services/worddict.js` 导出 `CLOUD_COLLECTION` + `staleCloud`；
- 页面校验 `col` 不符即回落本地。
- 回归 `.workbuddy/_smoke_find.cjs`（30 项）。

### toRow 不许伪造缺省值
`rawDiff||3` + `pad5(0)` 会返回非空串 `☆☆☆☆☆`，让「字段缺失」看起来像真实考频。
**缺值输出空串**，WXML 自然不渲染。筛选前必须先经 `toRow` 归一。

### 云端总数要单独取
`countWorddict` 返回 `{total, col}`；云端分支曾永远显示 `?`（2026-10-27 修）。

### ⚠ 自动配词写生词本必须搬 `definitions`（2026-10-27 修）
`autoWord.js#enrichCandidate` 漏搬 `definitions` → 雅思候选是客户端裸 `{word}` 串
（考研候选来自云端 `pick` 自带 definitions）→ 只有雅思词进生词本后卡片背面无中文释义。

修法：云端富词条取结构化 definitions；云端未命中回落本地 `d` 串；
加一次性回填 `enrichWordbookDefinitionsOnce`（flag `wordbookDefsV1`）。

## 二、文本渲染

### 切段高亮
**整段单一文本流 + 嵌套 `<text>`**（消除元素边界才能保留空白）。

- `markWords` 返回 `[{text, hit}]`，**空格留在片段文本里**；
- 外层 `.sr__en` 用 `display:block`。

❌ 错路：`space="nbsp"` / `pre-wrap` / 独立空格节点 / `inline-block` / `rich-text`（屏蔽事件）。

### 通用规则
- **事件写法**：自定义组件用 `bind:tap`，原生 `view` 用 `bindtap`（两者不通用）。
- 外层一律 `<view>`，叶子用 `<text>`，**不要 text 包 text**；class 不留空串。
- `<text>`：实体需 **`decode`**；**`user-select` 会变 inline-block**；不要 `display:block`。
- **构建函数返回字段要和 WXML `wx:if` 对齐**（漏返回字段 → 永不渲染）。

## 三、发音（云函数 base64 中转）

- 第三方音频域名过不了合法域名校验 → `cloudfunctions/tts` 代拉 → base64 直返 →
  前端写 `USER_DATA_PATH/tts/` → `InnerAudioContext` 播本地。
- 入口 `utils/tts.js#createTtsPlayer`。
- ⚠ 有道不总返回 MP3（abandon=ID3/MP3，communism=RIFF/WAV）→ 云函数按 magic bytes 嗅探 `ext`。
- **空间不是瓶颈，配额才是**：单次 ≈13KB；3000 次/月 × 67 人就打满 20 万/月调用 →
  **必须本地 LRU 缓存**（400 条 ≈5MB）。
- 估算脚本 `.workbuddy/tts_storage_estimate.cjs`。

## 四、主题（受控三档 light / dark / system）

- 深色是作用域类 `.mg-theme-dark`，`utils/theme.js#applyTheme` 挂到**页面根 view**
  （`class="mg-page {{themeClass}}"`，`onShow` 调 `applyTheme(this)`）。
- 脚本 `.workbuddy/_theme_wire.cjs --apply` 批量接线。
- **`page` 选择器也要声明变量**（原生弹窗 / 下拉刷新 / 越界区取 page 的值）；
  `.mg-page` 自带 background。
- ⚠ **禁用 `@media (prefers-color-scheme: dark)`**：真机无条件命中深色而开发者工具不模拟 →
  「工具正常、真机变深」。tabBar 深色做不到 → 已知瑕疵。

## 六、白屏 / 生命周期

- `storage.js` 同步异步混着：`get*` **同步**不能 `.then`；写类 **async**。
- **「页面只剩导航栏」＝ `onLoad` 抛异常** → 这类页面 `onLoad` 一律 try/catch 落可见错误态。
- `onShow` 早于首次渲染，里面抛异常会整页空白 → `applyTheme` 已全量 try/catch。

## 九、密钥与凭证（写代码时的红线）
- **SecretId（AKID 开头）本身就是敏感凭证**，「只有 ID 没有 Key 危害小」是错觉 →
  一样被 GitHub secret scanning 判定。**写日志只写「已能 echo 出来」，绝不写值本身。**
- **openid 同样不入库**：仓库公开 → 白名单只存 `sha256(openid)` 指纹。
  明文 openid 出现在测试脚本/日志里 = 违背自己的设计意图，必须脱敏。
- 排查全历史：`git grep -I -n -E "AKID[A-Za-z0-9]{20,}|sk-[A-Za-z0-9]{24,}" $(git rev-list --all) --`
- 详见 `docs/运维手册.md` 第一节（含已装的 `.githooks/pre-commit` 防护）。
