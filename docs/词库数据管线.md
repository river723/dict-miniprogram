## 一、.eudic 解析管线（`_tools/`）

### 数据源与格式
- 源文件：`_tools/_IELTS_src.eudic`
- **释义是分块 zlib 压缩**：每块解压后恰 16384 字节，共 39 块。
- 词条形如：`<b>word</b><div><div>[<font face="Lucida Sans Unicode">音标</font>]<br />义项…`

### 解析规则
- ⚠ **切段顺序不能反**：先 `split(/<br\s*\/?>/)` 再 `stripTags`。反了段落粘连。
- ⚠ 音标有三种写法，必须区分：
  1. 带 font 标签（绝大多数）
  2. 纯文本方括号 `[in5hibit]`（23 词）
  3. 学科标签 `[化][计][医]` —— **形似音标，必须用 `SUBJECT_TAGS` 排除**
- ⚠ 必须剥控制字符（压缩块尾部 NUL Padding）。
- 词表以 eudic 真实词头为准（4491 词）。
- ⚠ 词形误取校正：`ph` 去非字母后 == 单词本身 → 说明取错了，改用下一段音标（sphinx）。

### 验证纪律
⚠ **改解析器后必跑「旧产物 vs 新产物」diff，基线取 git 版本**——别拿自己刚跑出的坏产物当基线。

## 二、eudic 音标的 KK 字体编码（2026-10-20 修，53 条）

### 问题现象
比"19 词无音标"更隐蔽：eudic 对 **34 个词**给的不是 IPA，而是 **KK 字体编码**：

| 码 | 含义 | | 码 | 含义 |
|---|---|---|---|---|
| `5` | ˈ (主重音) | | `Q` | ʌ |
| `E` | eɪ | | `N` | ŋ |
| `I` | ɪ | | `F` | ʃ |
| `^` | ˌ (次重音) | | | |

页面会显示成 `in5hibit` / `sfiNks` / `tB:`。另有 8 条带未剥的 `(US)` 地域前缀。
上轮"补回 23 词音标"补的是**编码原文**，等于没修。

### 数据源
- `cdict_query` npm 包 → `_tools/ecdict_src/package/db/cdict2w.db`
  （SQLite，56992 词条；tarball 4.2MB / 解包 10MB）
- GitHub ECDICT 官方源全部拿不到：raw 是 git-lfs 指针、release zip 404、API 403 限流。
  **npm 镜像 `registry.npmmirror.com` 是可行入口。**
- 用 Node 22 内置 `node:sqlite` 的 `DatabaseSync` 读，**无需装 sqlite3 依赖**。

### 修复脚本
`_tools/fix_phonetics_from_ecdict.cjs`
- ECDICT 覆盖 42 条 + `OVERRIDES` 人工补 11 条 = **53/53 全解**
- 默认预览，`--apply` 才写盘

### 归一化四条坑
1. 剥前导尾缀时**不能碰 `:`**，否则 `tar 'tɑ:'` 会丢掉长音号
2. ECDICT 重音符位置不可靠（`misgiving 'mis'^iviŋ` → 词中重音 `ˈˌiviŋ`）→ **只留词首第一个**
3. 英式拼写在美式词典里查不到 → `variants()` 试 `-ise→-ize` / 双写辅音还原 / 去连字符
4. **别把「多读音条目」（`ˈkɔːdʒəl, ˈkɔːdiəl`）当坏数据** —— 曾顺带清尾分号误伤 7 个正常条目

### 判据 `isBadPh`
```
空 / 含 [0-9A-Z^] / 以 (US)|(UK) 开头
```
三者之外一律不动。

### 校验口径
git 基线 diff → **4491 词数不变、53 处变更全部只动 ph**（d/f/k 逐条比对）、
KK 残留 0、无音标 0。主包 993KB / 2048KB。

回归加了 4 项：无音标=0（阈值从 ≤20 收紧到 0）、无 KK 残留、无地域前缀、4 个污染词已归一。

⚠ ECDICT 二进制**不入库**（`.gitignore`），需要时重下。

## 三、雅思考频 / 难度重标（2026-10-19）

原数据是从考研库整条搬来的 + AI 凭记忆拍数字 —— 都不是雅思考频。

### 脚本
- `fetch_awl.cjs` → `awl_freq.json`
  AWL 570 词头/sublist + 3109 词形词频，**内置规格校验**，改版即报错。
- `relabel_ielts_metrics.cjs` → `ielts_metrics.json`
  - 考频 = **web 语料实测 ppm 绝对阈值**（Norvig，99.5% 覆盖）+ AWL sublist 加权
    （只上调不下调，直达星级映射）
  - 难度 = 纯客观（音节数 > 后缀 > 义项 > 词长）

### 四个坑
1. 两语料 ppm **不可混用** —— 学术语料抬高 19.4 倍 → 85% 挤 1★
2. 等分位数 ≠ 绝对阈值
3. 阈值须按实测分布校准
4. 词形表要做词形还原（`sublistOfForm`）

### 分布
- 考频：1048 / 1936 / 880 / 395 / 232
- 难度：1243 / 2101 / 723 / 333 / 91

回归：`.workbuddy/_smoke_metrics.cjs`（26 项）。
