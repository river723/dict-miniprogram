# 2026-09-15

## 政策核实：个人主体小程序已可开通虚拟支付（重要更正）

用户提出「2026 年微信放开个人小程序虚拟支付」，核实为**属实**，并更正了昨天方案里的错误结论。

### 官方口径（已抓官方文档原文）

来源：`developers.weixin.qq.com/miniprogram/dev/platform-capabilities/business-capabilities/virtual-payment/person`

- **生效时间**：2026-08-31 起（官方新增「虚拟支付：个人」章节）
- **开通条件**（三条，缺一不可）：
  1. 主体为个人、持大陆居民身份证
  2. **服务类目含「工具」**
  3. 已完成小程序认证（个人约 ¥30/年）+ ICP 备案
- **限额**：全终端合计 **10 万元/月**
- **费率**：安卓/鸿蒙等 **1%**（腾讯技术服务费）；iOS **12%**（Apple 佣金）
- **结算**：安卓 **T+3**；iOS **约 45–60 天**
- **结算账户**：个人主体用**本人储蓄卡**（不是对公）
- **商品形态**：文档明确**只做「道具直购」，不引入代币** → 没有"代币比例不可改"的坑
- **审核**：个人主体**一般 5 分钟内**出结果
- **不支持**：需办电信业务资质的服务（电子邮件、语音信箱、储存转发、信息发布平台、信息搜索查询等）

### 自媒体失真提醒

网上大量教程写「费率 0.6%、T+1 结算、自动提现、任意类目均可」（CSDN / 掘金等），
**与官方文档不符**。已按官方口径更正，并在文档里加了提示。

### 本项目适配性判断

- 产品形态（背单词 / 生词本 / 真题练习 / 短文精读）= 学习工具 → 天然适配「工具」类目
- 类目定位**不要**写成「教育 - 培训 / 课程」，否则个人主体失去开通资格
- 官方「Agent 自动接入」三种方式，**方式一就是"使用微信云开发快速接入"** ——
  本项目跑在微信云开发上，接入成本最低
- 接入坑：两套签名（paySig 用 AppKey、signature 用 sessionKey）；
  `post_body` 需与请求体完全一致；发货以**发货推送**为准 + `query_order` 兜底 + `wx_order_id` 幂等
