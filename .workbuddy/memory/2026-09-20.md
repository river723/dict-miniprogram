## 发音走云函数中转 —— 存储/配额核算（结论：空间不是问题，配额才是）

起因：提问"发音走云函数中转会不会占用大量空间"。实测而非估算：

**实测方法**：`import-data/worddict-*.json` 是 **JSONL**（一行一个 JSON，不能整体 `JSON.parse`），
逐行解析得 **4801 个唯一单词**。再从词库均匀抽 60 词，逐个请求
`https://dict.youdao.com/dictvoice?audio=<word>&type=2` 统计响应字节数 —— **60/60 成功**。

**结果**：均值 **13.29 KB**、中位 10.54、P90 12.98、最大 135KB（communism，个别异常长）。
→ 4801 词全量缓存 ≈ **62 MB**，仅为基础版 5GB 的 **1.22%**；上传 4801 次占 0.8%。

**真正的瓶颈（反直觉）**：不是存储空间，而是**每月配额** ——
基础版：CDN 流量 5GB/月、下载 150 万次/月、**云函数调用 20 万次/月**。
无本地缓存时，每次播放 = 1 云函数 + 1 下载 + 13KB CDN → **约 67 个重度用户(3000 次/月)就把
云函数调用打满**，比存储早 3 个数量级见底。

→ **方案必须带前端本地文件缓存**：`FileSystemManager.saveFile` 持久化 + `word→path` 存 storage，
实现"每个设备每个词只走一次云调用，重复播放 0 调用 0 流量"。
另可选：云函数直接返回 base64（零存储、零下载配额），但每次都要真拉有道，延迟更高。

**产出**：`.workbuddy/tts_storage_estimate.cjs`（可复跑，加 `--sample` 重新联网实测；
词库扩容后改 `WORDS` 即可重算）。

## 发音方案选型：base64 直返 vs 云存储中转（改动量评估）

现状（三处播放逻辑各自重复，都直接拼有道 URL）：
`study.js`(AUDIO_BASE + doPlay/maybeAutoPlay/playAudio，约 30 行)、
`word-detail.js`(playAudio 约 12 行)、`dictionary-word-detail.js`(playAudio 约 12 行)。

**base64 直返方案 ≈ 新建 2 文件(约 130 行) + 改 3 处(净减约 20 行重复代码) + 部署 1 个云函数**：
- 新建 `cloudfunctions/tts/`（index.js + package.json + config.json，约 60 行）
- 新建 `miniprogram/utils/tts.js`（约 70 行）：本地缓存查找 → 命中直接播；未命中
  callFunction → base64 writeFile 到 USER_DATA_PATH → 播；LRU + 并发去重
- 三处页面：`ctx.src = AUDIO_BASE + word` 换成异步取本地路径（study.js 改动最大，约 20 行）

**比云存储方案少约 1/3 代码**（后者还要加：云存储上传 + `tts_files` 集合 + 命中分支
+ 多一维配额：DB 读 / 下载次数 / CDN）。

**关键约束（已核实）**：
- 云函数返回给小程序端 **上限 1MB**；腾讯云官方"不建议把图片做成 base64 返回"——
  但那是针对动辄几百 KB 的图片，音频 13.29KB × 4/3 ≈ **17.7KB**，属安全区。
- `InnerAudioContext.src` **不能用 data URI**（不可靠）→ 必须 writeFile 到本地再播。
- **本地文件配额 200MB**（用户文件 + 缓存文件合计）：4801 词全缓存 62MB 占 31%
  → 必须 **LRU 限 300–500 词（4–6.5MB）**。
- Storage 存 word→filename 索引：总上限 10MB、单 key 1MB → 只存最近 N 个或分片。
- 首播延迟 0.5–1.5s（云函数 + 有道往返 + 冷启动），自动朗读场景建议**预取下一个词**。
- base64 唯一长期隐患：有道请求数 = 设备数 × 词数（1000 用户 × 4801 词 ≈ 480 万次），
  有被限流风险；云存储方案全局只有 4801 次。
- **演进路径干净**：先 base64，用户量上来后在同一个 `tts` 云函数内加"云存储命中则返回
  fileID"分支，前端 utils/tts.js 加一个分支即可，页面代码不动。
